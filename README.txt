МОЙ ИИ: личное приложение для локальной модели Ollama
=====================================================

Запуск: дважды щёлкните по my_ai.pyw
(если не открылось: в PowerShell выполните  pythonw C:\myhomeAI\my_ai.pyw )

Что где лежит
-------------
my_ai.pyw            запуск программы
backend\server.py    Python-код: сервер, связь с Ollama, сохранение данных
                     (вверху файла настройки: модель по умолчанию, память чата NUM_CTX)
frontend\index.html  страница (разметка окна)
frontend\css\style.css   оформление
frontend\js\app.js       логика интерфейса
frontend\themes\*.json   готовые темы
data\                создаётся само: чаты (chats), ваши темы (themes),
                     настройки (settings.json), журнал ошибок (log.txt)

Свои темы
---------
Способ 1: в приложении нажмите ⚙, вкладка «Цвета»: меняйте цвета, затем
«Сохранить как тему…».
Способ 2: скопируйте любой файл из frontend\themes в data\themes, переименуйте
(латиница, цифры, - и _), откройте в Блокноте и поменяйте "name" и цвета в формате
#rrggbb. Тема появится в списке после перезапуска приложения.
Любые цвета, которые вы не указали, берутся из темы «Полночь».

Как удалить
-----------
Закройте окно и удалите папку целиком. Чаты лежат в data\chats.
